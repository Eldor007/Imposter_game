# 🎭 Imposter — игра в Telegram

Любой участник создаёт игру в группе и становится ведущим. В личке он выбирает число импостеров и отправляет слово. Игроки переходят по кнопке «Участвую» и нажимают Start. Бот случайно выбирает импостеров, присылает им «Ты импостер», остальным — одинаковое секретное слово. Дальше игроки по очереди дают ассоциации и обсуждают их в группе. Управлять конкретной игрой может только её создатель.

## 1. Создать бота

В [@BotFather](https://t.me/BotFather) отправьте `/newbot`, задайте имя и username. Полученный **токен нужен только на сервере**. Создайте отдельного игрового бота: токен CRM-бота использовать нельзя.

Команды меню бот установит автоматически. Privacy Mode оставьте включённым. Добавьте бота в группу и разрешите отправлять сообщения. Права администратора не требуются ни боту, ни ведущему. Команды отправляйте от личного аккаунта, чтобы бот мог определить создателя игры.

## 2. Установить на Ubuntu-сервере

Откройте терминал своего сервера либо подключитесь по SSH (замените `YOUR_SERVER` адресом сервера):

```bash
ssh root@YOUR_SERVER
```

Один раз выполните:

```bash
sudo git clone https://github.com/Eldor007/Imposter_game.git /opt/imposter-bot
cd /opt/imposter-bot
sudo bash deploy/install.sh
```

Когда появится `Paste NEW game bot token from BotFather`, вставьте токен и нажмите Enter. Ввод скрыт. Скрипт проверит токен, сохранит его в `/etc/imposter-bot.env` с правами 600 и включит службу с автозапуском. Если токен неправильный: `sudo nano /etc/imposter-bot.env`, затем повторите установку. Формат файла:

```dotenv
BOT_TOKEN=123456789:YOUR_BOTFATHER_TOKEN
```

Нужен Python 3.10+ и Git. Бот работает через long polling и исходящий HTTPS к `api.telegram.org:443`. Домен, Cloudflare, веб-сервер, PostgreSQL и входящие порты для него не нужны. Служба ограничена 128 МБ памяти; игровые данные лежат отдельно в `/var/lib/imposter-bot/state.json`. Запускайте только один экземпляр с данным токеном.

## 3. Играть

1. Добавьте бота в Telegram-группу.
2. Любой участник пишет `/start@YOUR_BOT_USERNAME` и нажимает «Новая игра» (или сразу отправляет `/newgame`). Он становится ведущим. Затем нажимает «Настроить игру».
3. В личке бот спрашивает число импостеров (есть кнопки 1/2/3), затем слово.
4. Игроки нажимают «Участвую / открыть бота» в группе, затем Start. Это сразу регистрирует игрока и разрешает боту присылать ему сообщения.
5. Ведущий нажимает «Раздать роли» в группе или личке. Нужен хотя бы один обычный игрок, максимум 50 игроков.
6. Бот присылает роли. Игроки дают ассоциации и голосуют сами в группе. Ведущий нажимает «Завершить и показать результат» — бот раскрывает слово и импостеров. Затем доступна «Следующая игра».

### Живое табло и результаты

В сообщении лобби автоматически обновляются список игроков, ведущий, количество импостеров и этап игры: настройка, набор, раздача, игра, завершена. После раздачи отображается число доставленных ролей. Роли и слово до завершения скрыты.

Любой участник может отправить `/status` (или `/players`) в группе, чтобы вывести табло, либо нажать «Обновить статус». Исходное лобби и три последних табло обновляются при изменениях; более старое сообщение можно обновить кнопкой. Команда `/results` показывает текущее состояние, а после завершения — раскрытые роли. Только ведущий может завершить игру кнопкой или `/finish`. Победителя бот автоматически не определяет: обсуждение и голосование проходят среди игроков в группе. Результат сохраняется до создания следующей игры.

Ведущий знает слово и не участвует в раздаче. Кнопка «Отменить игру» доступна создателю; также работают `/stop` в группе и `/cancel` в личке. После начала раздачи завершение через `/stop` или `/cancel` раскрывает результат. Сообщения с ролями защищены от пересылки средствами Bot API. Если доставка не удалась, повторное нажатие «Раздать роли» досылает роли, сохраняя назначенных импостеров.

Игровое состояние сохраняется при перезапуске. При сетевом сбое непосредственно после доставки сообщения возможна повторная доставка той же роли; назначения сохраняются. Ведущий может одновременно настраивать только одну игру.

## Обновление и обслуживание

После нового коммита на GitHub выполните на сервере:

```bash
sudo bash /opt/imposter-bot/deploy/update.sh
```

Проверить работу:

```bash
sudo systemctl status imposter-bot --no-pager
sudo journalctl -u imposter-bot -n 30 --no-pager
```

Остановить: `sudo systemctl stop imposter-bot`. Изменить токен: `sudo nano /etc/imposter-bot.env`, затем `sudo systemctl restart imposter-bot`.

## Разработка

Python 3.10+, внешние библиотеки не нужны. В PowerShell: `$env:BOT_TOKEN="..."; python bot.py`. В Linux: `BOT_TOKEN='...' python3 bot.py`. Тесты без Telegram: `python -m unittest discover -s tests -v`.
