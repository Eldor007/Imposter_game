# 🎭 Imposter — Telegram-игра в ассоциации

Любой участник может создать игру. Бот проводит её до результата: личные роли → ассоциации по очереди → обсуждение → тайное голосование → выбывание → победитель. Все действия доступны кнопками. В группе редактируется одно табло, в личке — одна панель на участника и игру.

## Как начать

1. Добавьте бота в группу. Появится кнопка **«Новая игра»**.
2. Создатель нажимает **«Создателю: настройка»** и выбирает режим в личке:
   - **«Играю со всеми»** — бот выбирает случайное слово. Создатель тоже играет и может оказаться импостером.
   - **«Я ведущий, своё слово»** — создатель отправляет слово и наблюдает, не участвуя в раздаче.
3. Выберите число импостеров кнопкой 1/2/3 или отправьте число до 20. Для N импостеров нужно минимум 2N+1 игроков; максимум 50.
4. Игроки нажимают **«Участвую»** в группе и Start в личке. Telegram требует этого, прежде чем бот сможет присылать личные роли.
5. Создатель нажимает **«Начать игру»**. Управлять игрой может её создатель; права администратора не нужны.

При первом добавлении бот сам показывает меню. Для уже добавленного бота можно один раз открыть меню командой `/start@YOUR_BOT_USERNAME`. Дальше команды не требуются. Privacy Mode можно оставить включённым.

## Полный игровой цикл

- **Ассоциации:** каждый получает до 45 секунд. Можно написать ассоциацию боту в личку, ответить на групповое табло или сказать её в группе/голосом и нажать **«Ассоциацию сказал»**. Очередь и ассоциации видны в табло. Молчащего игрока пропустит таймер; создатель также может пропустить ход из личной панели.
- **Обсуждение:** 60 секунд. Большинство оставшихся игроков кнопкой **«Готов голосовать»** может начать голосование раньше. Создателю также доступна эта возможность.
- **Голосование:** 60 секунд. Нажмите **«Проголосовать в личке»** и выберите подозреваемого кнопкой. Выбор скрыт от других; до закрытия его можно изменить. Себя выбрать нельзя. Есть «Пропустить голос», большие списки разбиты на страницы. Если все проголосовали, подсчёт начинается сразу. Кто не успел — воздержался.
- **Выбывание:** исключается игрок с наибольшим числом голосов; его роль раскрывается. При ничьей проводится одно переголосование между лидерами. При повторной ничьей, отсутствии голосов или победе варианта «Пропустить» никто не выбывает, начинается новый круг.
- **Победа знатоков слова:** все импостеры найдены. У последнего пойманного есть 30 секунд и одна попытка угадать слово в личке. Если он не угадал, знатоки победили.
- **Победа импостеров:** слово угадано последним пойманным, либо импостеров осталось не меньше обычных игроков, либо три голосования подряд никто не выбыл.
- **Результат:** табло раскрывает слово, импостеров и причину победы. Личная статистика игр и побед доступна через **«Мои игры»**.
- **Реванш:** создатель нажимает **«Реванш тем же составом»**. Участники и панели сохраняются; слово и роли выбираются заново. В режиме своего слова ведущий задаёт новое слово. Кнопка **«Новая игра»** открывает пустое лобби для любого нового создателя.

Несколько импостеров видят своих напарников в личной роли. Выбывшие остаются наблюдателями, но не голосуют. Вход и выход из состава закрываются после начала раздачи. Не начавшее игру лобби закрывается через 30 минут. Досрочное завершение требует подтверждения и не засчитывает победу.

## Табло без спама

Одно сообщение в группе показывает состав, очередь, этап, таймер, число доставленных ролей, ход голосования и итог. При входе/выходе и смене этапа бот **редактирует это сообщение**. Реванш использует то же табло. Ведущий и игроки видят актуальное состояние в своих личных панелях.

Короткие нажатия подтверждаются всплывающими уведомлениями. Отдельные сообщения появляются для первой личной панели, ошибки текстового ввода или если прежнее табло удалено и его надо восстановить. Меню «Мои игры» — отдельное личное сообщение, не публикуемое в группе.

Частые события объединяются; групповое табло обновляется не чаще примерно одного раза в 3 секунды. Таймер округлён до 15 секунд; переходы проверяются каждые 2 секунды. Изменение сообщения не вызывает нового push-уведомления Telegram: держите табло под рукой или закрепите его вручную. `/status`, `/players`, `/results` оставлены для совместимости и также обновляют существующее сообщение.

До финала публичное табло не показывает слово и роли оставшихся игроков. Личные панели защищены от пересылки средствами Bot API. У каждого игрока есть только одна личная панель на игру; уже доставленные роли при повторной доставке не меняются.

## Установка на Ubuntu

Python 3.10+ и Git. Сторонние Python-библиотеки, база данных, Docker, домен и входящие порты не нужны. Требуется исходящий HTTPS к `api.telegram.org:443`.

1. Создайте отдельного бота через [@BotFather](https://t.me/BotFather), командой `/newbot`.
2. В терминале сервера выполните:

```bash
sudo git clone https://github.com/Eldor007/Imposter_game.git /opt/imposter-bot
cd /opt/imposter-bot
sudo bash deploy/install.sh
```

Когда скрипт попросит токен, вставьте его и нажмите Enter. Ввод скрыт; токен сохраняется только в `/etc/imposter-bot.env` с правами 600. Не используйте токен другого работающего бота. Меню команд устанавливается автоматически.

Служба `imposter-bot` работает от отдельного пользователя, ограничена 128 МБ памяти и запускается после перезагрузки. Состояние: `/var/lib/imposter-bot/state.json`. Не запускайте второй экземпляр с тем же токеном или файлом состояния.

## Обновление с сохранением игры

```bash
sudo git -C /opt/imposter-bot pull --ff-only origin main
sudo bash /opt/imposter-bot/deploy/update.sh
```

Обновление запускает тесты, проверяет совместимость сохранения, останавливает только эту службу, делает резервную копию состояния в `/var/backups/imposter-bot/` и запускает новую версию. Другие приложения сервера не затрагиваются.

При переходе с первой версии участники, слово, назначенные роли и основное групповое табло сохраняются. Начатая старая игра продолжится с обсуждения перед голосованием; последняя личная панель ведущего будет переиспользована. Новые голосования, сроки и выборы сохраняются после перезапуска. После простоя бот переводит только текущий просроченный этап, давая следующему игроку полный ход.

Если Telegram принял сообщение, а сеть оборвалась до подтверждения, при повторе возможно дублирование первого сообщения. Назначения ролей сохраняются до отправки и не меняются. Это ограничение доставки Bot API; обычные действия и обновления табло не создают новые сообщения.

```bash
sudo systemctl status imposter-bot --no-pager
sudo journalctl -u imposter-bot -n 50 --no-pager
```

Изменение токена: `sudo nano /etc/imposter-bot.env`, затем `sudo systemctl restart imposter-bot`.

## Разработка и проверки

```bash
python -m unittest discover -s tests -v
python bot.py --check-state
```

`game.py` — правила и переходы, `ui.py` — тексты и кнопки, `storage.py` — совместимые атомарные сохранения, `bot.py` — Telegram, доставка и таймеры. Тесты не используют токен и не отправляют сообщения в Telegram. CI проверяет Python 3.10 и 3.13.

Для локального запуска задайте `BOT_TOKEN` в окружении. На PowerShell: `$env:BOT_TOKEN="..."; python bot.py`. На Linux: `BOT_TOKEN='...' python3 bot.py`.

## Донаты — следующий этап

В этой версии платежи не включены. План — добровольная поддержка через Telegram Stars в личном меню и после игры. Она не будет менять роли, голоса или шансы на победу. Перед включением нужны тестовый платёж, сохранение идентификаторов транзакций, поддержка обращений и возвратов. См. [официальный Payments API для Stars](https://core.telegram.org/bots/payments-stars).

## Изученные игровые интерфейсы

Использованы общие паттерны из [Werewolf for Telegram](https://www.tgwerewolf.com/) (личные кнопки выбора игрока, настройка в личке) и [Wolf Blood](https://www.tgwolfblood.com/home/index) (вход кнопкой из группы, личные роли, этапы обсуждения и голосования). Конкретные роли, тексты и код этих проектов не копировались. У Imposter своё слово, ассоциации и последняя попытка угадать его.
